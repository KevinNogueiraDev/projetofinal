\# Fundamentos em C para iniciantes



Um guia introdutório sobre os fundamentos da linguagem C, desenvolvido como material de apoio para estudantes interessados na Apple Developer Academy.

\---

\## Objetivo



Apresentar conceitos básicos de programação e a sintaxe da linguagem C.
---

\## Público-alvo



Iniciantes em programação e que desejam conhecer os fundamentos da linguagem C, especialmente aqueles que possuem interesse na Apple Developer Academy.

\---

\## Pré-requisitos



Não é necessário conhecimento prévio em programação.



É recomendado ter:



Um computador;

Um compilador de C (pode usar o site GDB online Debugger para codar);

Disposição para praticar os exemplos e exercícios apresentados.
---

\## Estrutura do guia



O conteúdo está organizado da seguinte forma:



docs/01-introducao.md — Introdução à programação e à linguagem C.

docs/02-conceitos.md — Principais conceitos e estruturas da linguagem.

docs/03-exercicios.md — Exercícios para praticar os conteúdos apresentados.

docs/04-referencias.md — Materiais utilizados como referência.

exemplos/respostas\_exercicios.md — Exemplos que servem de resposta para os exercícios em C.
---

\## Instruções de navegação



Recomenda-se seguir os arquivos na ordem apresentada, começando pela introdução e avançando para os conceitos, exercícios e referências.



Os exemplos podem ser consultados durante o estudo para ajudar na compreensão dos conceitos.
