\# Aprendizados

Ao criar este projeto, pude consolidar os conhecimentos adquiridos ao longo da trilha. Aprendi, na prática, a inicializar repositórios com git init, acompanhar o estado dos arquivos com git status e visualizar o histórico de commits de forma concisa usando git log --oneline. Além disso, pratiquei a criação e integração de branches, a abertura e gerenciamento de Pull Requests, e compreendi como gerar e resolver conflitos de merge. Apesar dos desafios enfrentados durante o processo, a experiência ajudou a fixar esses conceitos de forma muito mais sólida.
