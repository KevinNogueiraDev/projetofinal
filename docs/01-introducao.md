\# Introdução à programação em C



\## O que é programação?



Programação é o processo de criar instruções para que um computador

execute determinadas tarefas.



\## O que é uma linguagem de programação?



Uma linguagem de programação é uma forma estruturada de escrever

instruções que podem ser interpretadas ou compiladas para que o

computador possa executá-las.



\## O que é C?



C é uma linguagem de programação criada na década de 1970.

Ela é conhecida por oferecer controle sobre recursos do computador

e possui uma sintaxe que influenciou diversas outras linguagens.
